Full text: https://dejavu-fonts.github.io/License.html

These font files are bundled ONLY so that PDF export always has a Unicode
font capable of rendering Vietnamese diacritics (Đ, ắ, ộ, …). The fonts are
not modified.

If you prefer not to ship the fonts, delete this folder: `export_utils.py`
will fall back to a system font (Arial/Calibri/DejaVu/Liberation) and raise a
clear error if none is available.
